# 管理規約 改正対応チェック

## 前提
- 対象：単棟型のマンション。比べる相手は「マンション標準管理規約（単棟型）令和7年10月17日改正」
- 区分所有法は、令和7年法律第47号による改正後（2026年4月1日施行）の条文を使う
- 2026年4月1日以降に招集する総会には改正法が適用される。施行の際に効力を持つ規約の定めのうち、改正法に**抵触するものは施行日から効力を失う**（令和7年改正法 附則第2条第3項）
- 出力は「総会提案の下書き」であり、法的助言ではない

## 手順
1. `list_articles` で現行規約の全体像をつかむ
2. `reference/topics.md` の論点表を読み、論点ごとに次を行う
   - 現行規約で対応する条を探す。条番号は標準管理規約と同じとは限らないので、見出しと内容で探す
   - `get_articles` で現行規約の本文を、`get_standard_articles` で標準管理規約の本文を、`get_law_articles` で区分所有法の条文を取得し、照らし合わせる
   - 改正後の標準管理規約・改正法と食い違う場合は指摘にする。すでに対応済みなら指摘しない
3. 論点表にない差分（電磁的方法の整理など）は、標準管理規約と比べて意味のある違いがあり、根拠を示せるものだけを「参考」として指摘する
4. 指摘は `record_findings` で記録する。受け付けられなかった指摘は、返ってきた理由に従って直して送り直す
5. 最後に、件数と、担当者が判断すべき点を短くまとめる

## 指摘の書き方
- **根拠を示せない指摘は出さない**。区分所有法の条文（例：「第31条第1項」）か、標準管理規約の条番号（例：「第47条第3項」）を必ず付ける
- `current_excerpt` には、`get_articles` で取得した本文から一字一句そのまま引用する。現行規約に規定そのものがない場合は、`article` を「規定なし」、`current_excerpt` を空にする
- `issue` は、専門家でない理事会の担当者が読んで分かる言葉で書く。法律用語を使うときは短く言い換える
- 区分
  - **必須**：論点表で「必須」のもの。改正法に抵触する、または国交省が必ず盛り込むよう求めているもの
  - **推奨**：論点表で「推奨」「要確認」のもの。「要確認」は、法に抵触するかを一次資料で確認できていない論点
  - **参考**：論点表にない、標準管理規約との意味のある違い
- **規約か細則か**（`where`）：規約の変更は特別決議（区分所有法第31条第1項、標準管理規約第47条第3項第一号）。使用細則などの細則の変更は普通決議で足りる（標準管理規約第48条第一号、第47条第2項。根拠は第18条・第70条）。総会・理事会の運営、会計処理、届出事項など、標準管理規約が細則に委ねている事項は「細則で対応可」とする
- **選択式の規定**：標準管理規約に（ア）（イ）などの選択肢がある場合（例：電磁的方法が利用可能か）は、勝手に選ばず `choice_needed` を true にし、`choice_note` に選択肢と判断のポイントを書く
- 1つの条に複数の論点がある場合（第47条など）は、論点ごとに別の指摘にする

## してはいけないこと
- 根拠のない推測で指摘を作る
- 現行規約にない文言を引用する
- 法的な結論を断定する（「無効です」ではなく「改正法に抵触し、効力を失うおそれがあります」）
