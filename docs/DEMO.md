# 3分デモ動画の台本（DEMO）

11/3 に、今の画面の流れ（点検 → 指摘の判断 → 改定案 → 理事会での検討 → 住民向けの説明 → 総会後の最新規約）に合わせて書き直した。
数字の裏付けと言い方の注意は、末尾の付録にまとめた。

## 方針
- **最初の30秒で「日本のマンションの驚き」と「課題の大きさ」を伝える**。3:00を超えた部分は見てもらえない
- 海外の審査員向けに、**英語の字幕**を全編に付ける。画面とナレーションは日本語のまま（CLAUDE.md）
- 当事者のコメントは撮らない（11/3 決定）。作り手自身が規約見直しの当事者であることを、ナレーションで一言だけ伝える
- **期間中に作った機能だけ**を映す。コード画面は出さず、構成図1枚で代える
- 実在の規約・マンション名・住民名は映さない。**サンプル「Word の規約集（架空）」**を使い、マンション名は「さくら台マンション管理組合（架空）」と入れる
- AI の待ち時間は早送りし、画面の隅に「実時間 4分」のように出す（ごまかさない）
- 「総会提案の下書きであり、法的助言ではない」ことを画面に映す（締めの場面）

### B. 課題の場面の裏付け：多くのマンションは規約が追いついていない（11/3 調査）
伝えたいこと：老朽化と高齢化に合わせて法律が改正されてきたが、多くのマンションの規約は追いついていない。古い規約のまま総会を開くと、決議の効力が争われ、やり直しになるおそれがある。大規模修繕のような大きな決定だと、工事の契約・着工のあとでは後戻りできない。

#### 古い規約のままのリスク（言い過ぎない）
- 改正法の施行日（2026年4月1日）以降、規約のうち改正法に抵触する定めは効力を失う（令和7年改正法 附則第2条第3項。国交省「手続の留意点」：data/public/mlit/r7_kaisei_tetsuzuki_ryuuiten.pdf）
- 例：古い規約の「緊急時は5日前に招集できる」に従って総会を開くと、改正法の「1週間前」（第35条第1項）に反する。議案の要領を一部の議案にしか書かない古い定めも同じ
- 手続きが法律に反した総会の決議は、効力を争われ、やり直しになる**おそれがある**（無効になるかは個別の判断。「必ず無効」とは言わない）
- 大規模修繕の決議のあとで工事の契約・着工が進むと、後戻りが難しい
- ナレーション案：「古い規約のまま総会を開くと、せっかくの決議が、あとから争われるかもしれません。何千万円もの大規模修繕を決めたあとで、です」
