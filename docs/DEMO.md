# 3分デモ動画の台本（DEMO）

## 方針
- 最重要ポイントは冒頭30秒に置く。3:00を超えた部分は審査員に見てもらえない
- コード画面は出さず、構成図1枚で代える
- 期間中に作った機能だけを映す
- 実在の規約・住民名は映さない。旧版の標準管理規約などのサンプルで見せる
- 日本語ナレーション＋字幕。録画は1080p以上・全画面・通知オフ

## 課題の場面（0:15–0:40）の裏付け：多くのマンションは規約が追いついていない（11/3 調査）
伝えたいこと：老朽化と高齢化に合わせて法律が改正されてきたが、多くのマンションの規約は追いついていない。古い規約のまま総会を開くと、決議の効力が争われ、やり直しになるおそれがある。大規模修繕のような大きな決定だと、工事の契約・着工のあとでは後戻りできない。

### 数字（一次資料で確認済み）
国交省「令和5年度マンション総合調査」データ表 20③「マンション標準管理規約への準拠状況」（管理規約を改正したことがある1,369組合）

| 準拠状況 | 割合 |
| --- | --- |
| 令和3年度改正後の標準管理規約に概ね準拠 | 35.9% |
| 令和3年度改正後の標準管理規約に一部準拠 | 6.4% |
| **令和3年度改正前（古い版）**の標準管理規約に概ね準拠 | 35.0% |
| **令和3年度改正前（古い版）**の標準管理規約に一部準拠 | 14.8% |
| 全く準拠していない | 3.8% |
| 不明 | 4.2% |

- 最新の版（当時）に沿っているのは **42.3%** だけ。**約半数（49.8%）は古い版**のまま。調査は2023年で、2021年の改正から約2年後
- 管理規約を一度も改正したことがない組合も **7.7%**（データ表 20②）
- 出典：https://www.mlit.go.jp/jutakukentiku/house/content/001750163.pdf （データ表 20②・20③）。新宿区も同じ数字（42.3%）を引用している：https://www.city.shinjuku.lg.jp/seikatsu/jutaku01_000001_00066.html
- 動画では「2023年の国の調査で、最新の標準に沿った規約は4割ほど。半数は古い版のまま」と言う。2026年の法改正への対応状況そのものの調査ではないことに注意（「法改正に対応できていないマンションが半数」とは言わない）

### 古い規約のままのリスク（言い過ぎない）
- 改正法の施行日（2026年4月1日）以降、規約のうち改正法に抵触する定めは効力を失う（令和7年改正法 附則第2条第3項。国交省「手続の留意点」：data/public/mlit/r7_kaisei_tetsuzuki_ryuuiten.pdf）
- 例：古い規約の「緊急時は5日前に招集できる」に従って総会を開くと、改正法の「1週間前」（第35条第1項）に反する。議案の要領を一部の議案にしか書かない古い定めも同じ
- 手続きが法律に反した総会の決議は、効力を争われ、やり直しになる**おそれがある**（無効になるかは個別の判断。「必ず無効」とは言わない）
- 大規模修繕の決議のあとで工事の契約・着工が進むと、後戻りが難しい
- ナレーション案：「古い規約のまま総会を開くと、せっかくの決議が、あとから争われるかもしれません。何千万円もの大規模修繕を決めたあとで、です」
