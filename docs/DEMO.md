# 3分デモ動画の台本（DEMO）

## 方針
- 最重要ポイントは冒頭30秒に置く。3:00を超えた部分は審査員に見てもらえない
- コード画面は出さず、構成図1枚で代える
- 期間中に作った機能だけを映す
- 実在の規約・住民名は映さない。旧版の標準管理規約などのサンプルで見せる
- 日本語ナレーション＋字幕。録画は1080p以上・全画面・通知オフ

## 構成
| 時間 | 場面 | 見せるもの・語ること | 効く審査基準 |
| --- | --- | --- | --- |
| 0:00–0:15 | フック | 規約冊子と総会資料。「私は今、管理組合で規約の見直しを担当しています」 | インパクト |
| 0:15–0:40 | 課題 | 改正法の施行、古い規約のままのリスク、旧版準拠の割合、専門家費用（数字は要確認） | インパクト |
| 0:40–1:10 | デモ① 洗い出し | 規約を投入。条文ごとに処理が進む画面。要対応箇所が根拠条文付きで並ぶ | デモ、Claudeの活用 |
| 1:10–1:40 | デモ② 改定案と対照表 | 1つの指摘を開き、改定案と新旧対照表が生成される | デモ、深さ |
| 1:40–2:05 | デモ③ 住民向け説明 | 同じ変更を、住民が読める説明文に変換し、総会資料として出力 | デモ、インパクト |
| 2:05–2:30 | 信頼性と仕組み | 国交省の新旧対照表との一致率、エージェント構成の図 | Claudeの活用、深さ |
| 2:30–2:50 | 実際に使う | 評価の数字（必須の検出、採点役の確認）と、作り手自身の委員会で使う予定をナレーションで（当事者のコメント撮影はしない。11/3 決定） | インパクト、深さ |
| 2:50–3:00 | 締め | 「専門家に頼めなかった組合でも、自分たちで規約を守れる」とリポジトリURL | インパクト |

## 撮りためる素材
- 毎日の終わりに、その日の画面を1本録画する
- 生成待ちは早送りし、「実時間◯分」と表示する

## 見直し予定（11/3）
- この台本は 11/2 時点のもの。理事会での検討、〔選択〕、規約と細則（特別決議・普通決議）、採点役の確認、総会後の最新規約、進め方の案内を反映して書き直す
- 海外の審査員に伝わる日本らしさと英語の字幕を入れる（docs/DESIGN_IDEAS.md）
- 当事者のコメントは撮らない。作り手自身が当事者であることを冒頭のナレーションで伝える

## 冒頭30秒の案：日本のマンション事情で驚かせる（11/3 ユーザー提案）
海外の審査員は日本のマンションの仕組みを知らない。冒頭で「住民自身が管理する」「1,500万人」「高齢化」「法改正」を数字で見せ、驚きと課題の大きさを同時に伝える。英語の字幕を付ける。

| 時間 | 画面 | 字幕・ナレーション |
| --- | --- | --- |
| 0:00 | 日本の団地・マンションが並ぶ景色 | 日本では、1,500万人が分譲マンションに住んでいる。10人に1人 |
| 0:06 | 集会室での総会の様子（イラスト） | 管理するのは会社ではない。住民自身（管理組合） |
| 0:12 | 数字 | 世帯主の4人に1人は70歳以上。築40年を超える建物は20年で3倍以上に |
| 0:19 | 法律の条文 → 古い規約の冊子 | 2026年4月、法律が変わった。古い規約のままでは、決めごとが効力を失うおそれ |
| 0:25 | 作り手（顔なしでも可） | 半数以上の管理組合は専門家に頼ったことがない。私もその一人。だから作った |

### 使う数字（一次資料で確認してから使う）
参考：かわさきマンション管理組合ネットワーク「理事向け冊子」（2026年7月版）。いずれも国交省の調査の引用なので、動画には一次資料を出典として出す。冊子のグラフ・写真は使わない（数字だけ使い、図は自作）。
