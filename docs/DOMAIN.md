## 「必須」の法的な根拠
- **令和7年改正法 附則第2条第3項**：施行の際に効力を持つ規約で定めた事項のうち、新しい区分所有法に**抵触するものは、施行日（2026年4月1日）から効力を失う**
- **附則第2条第2項**：施行日より前に招集手続きが始まった集会には、従前の例による。今日（11/2）以降に招集する総会は、すべて改正法に従う

## 区分の付け方
国交省【概要】の凡例をそのまま使います。

- **◎**：標準管理規約に準拠した変更をしないと、区分所有法に抵触するなど、管理規約の変更が必須のもの → 本ツールの「**必須**」
- **○**：抵触はしないが、適合させることが望ましいもの → 本ツールの「**推奨**」
- **無印**（社会情勢等をふまえた見直し）→ 本ツールの「**推奨**」
- 過去の改正（平成28年〜令和6年）の取り込み漏れ → 本ツールの「**参考**」（別に整理する）

ただし、◎は【概要】では**テーマ単位**で付いています。同じテーマの中でも、法に抵触するかどうかは項目ごとに違うので、「項目ごとの判定」の列に分けて書きました。

## 要確認として残っていること
- 1-4、1-5：3/4 や 4/5 のままの規約が、法に抵触して無効になるのか（規約で要件を加重できるか）。1-6 は 11/3 に必須とした
  - 11/3 の条文の確認（e-Gov の改正後の条文）：
    - 1-4（第17条第1項・第5項）：出席の要件は規約で上げられる。決議の割合は「4分の3（これを下回る割合（2分の1超）を規約で定めた場合はその割合）」で、規約で**下げる**ことだけを認める。第5項は瑕疵の除去・バリアフリー化について「4分の3」を「3分の2」と読み替える。規約で割合を上げる文言はないので、第31条と同じ理屈なら、3分の2の区分を設けずに4分の3（全員母数でも出席者でも）のままの規約は抵触する
    - 1-5（第62条、第64条の5〜第64条の8）：決議の割合に規約の文言は一切ない（第61条・第31条と違い、出席の要件もない全員母数）。第62条第2項の客観的な事由（耐震性の不足など）があれば4/5を3/4に読み替え、更新・敷地売却・取壊しの決議にも準用する。古い規約の「建替え決議は4/5」は、事由がない場合は法と同じだが、事由がある場合に法より重くなり、その場面で抵触する。更新・取壊しなどの新しい決議の定めがないこと自体は抵触ではない（法がそのまま適用される）
    - どちらも、国交省・法務省の資料で名指しした判断は見つけていない（1-6 と同じ）
- 2-3：緩和事由の通知の、法令上の根拠（省令などにあるか）
- 「その他所要の改正」に当たる条（第2条、第44条、第46条、第48条、第54条、第58条、第64条、第67条 など）の区分
