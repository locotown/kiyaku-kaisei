# デモ動画で使う素材と出典

動画に入れる写真・イラスト・図の出どころと利用条件。素材集の写真や撮影した映像に差し替えたら、ここに追記する。

## 方針
- 実在のマンションが特定できるもの（建物名・看板・住所表示・表札・車のナンバー・顔の分かる人）は使わない。作り手の住まいは撮らない
- 素材集の写真は、素材ごとに利用規約（動画への利用、クレジット表記、人物写真の制限）を確かめてから使う
- AI で作った写真風の画像は使わない（実在の場所に見えて誤解を招くため）
