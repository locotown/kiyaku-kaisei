# デザインの見直し（メモ）

11/3 にユーザーから。仕様がある程度固まり、機能がほぼ完成したら、全体のデザインを見直す。

## 目指すもの
- もっと質の高い UI と UX。デザイン性が高く、圧倒的に使いやすいもの
- 米国企業のハッカソンなので、海外の審査員に「驚き」が伝わるようにする
  - 日本的な要素を入れる
  - 日本の集合住宅（分譲マンション・管理組合・総会）は日本独自の仕組み。それが伝わる写真やビジュアルにする
- デモ動画でも、日本の要素が伝わるようにする

## アイデアの候補（未決定。見直しのときに検討する）
- 管理組合の手続きの「日本らしさ」を見た目に使う
  - 理事会の判断・総会の可決を「判子（印影）」で表す
  - 住民向けの説明を「回覧板」「掲示板の掲示物」の体裁で出す
  - 最新の規約の印刷用は、規約集らしい体裁（縦書きの選択肢、和暦の日付はすでに対応）
- 日本の集合住宅が伝わるビジュアル（団地・分譲マンションの外観、集会室での総会の様子など）
- デモ動画：英語の字幕を付ける。冒頭で「日本のマンションは住民が管理組合をつくり、規約を総会で決める」ことを短く説明する

## 守ること（CLAUDE.md・docs/SPEC.md）
- 画面と出力は日本語のまま（デモ動画の字幕は英語でよい）
- 実在のマンションの写真・名前・住民名・部屋番号は使わない。写真は自分で撮ったもの・利用条件を確認した素材・イラストにする
- 法的助言ではない旨の表示は残す
