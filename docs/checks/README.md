# 人の確認（確認ボード）

AI が確かめられることは AI が確かめ、使う人が実際に使ってはじめて分かることだけを、人に確かめてもらう仕組み。
改善の区切りごとに「回」を作り、結果を次の改善に戻す。

- 確認ボード：https://claude.ai/artifact/YXGEc4qZ7g8QrxVvJZdoyV （claude.ai の非公開ページ。開けるのは作者だけ）
- 回ごとの記録：このフォルダの `r01.md`、`r02.md` ……

## 流れ

1. Claude：改善を作り、自分で確かめる（自動テスト、画面のスクリーンショット、架空のサンプルでの通しの動作確認）
2. Claude：確認を2つに分ける
   - AI が確かめたこと：ボードの回に一覧で載せる（人は確認しなくてよい）
   - 人に確かめてほしいこと：人でないと分からないことだけ（実物の規約・紙とペンとスマホ・Word やプリンタの実物・会議の流れに合うか・言葉が通じるか）。1回10項目程度まで
3. Claude：ボードに新しい回を載せ（ArtifactData で `rounds`・`items` に書く）、ここに `rNN.md` を残す
4. 人：ボードで項目ごとに「確認できた／問題あり／見送り」を選び、メモを書く。項目にないことは「気づき」に書く。直してほしいことは、回の終わりを待たずに、その項目の「Claude に直してもらう」で頼み、チャットに「ボードを見て」と送る（Claude は頼まれた項目と未対応の気づきだけを読んで直す）。全部終わったら「この回を閉じる」
5. Claude：ボードの結果を直接読む（`results`・`notes`。頼まれたものは `ask: true`）。問題は直し、できる限り自動テストに変えて、次からは AI が確かめるようにする。返事はボードの項目・気づきに書く（`reply`・`reply_at`。対応したら `ask` を外す）
6. Claude：`rNN.md` の「結果の要約」を書く。直した分は次の回に「直したので確かめて」として載せる

## 添えた画像

項目のメモ欄と「気づき」には、画面のキャプチャを添えられる（ボタン・⌘V の貼り付け・ドラッグ）。画像はボードの保存場所（claude.ai の非公開ページ。開けるのは作者だけ）に置かれ、記録には画像の id だけが残る（`results.images`・`notes.images`）。
Claude は id から画像を取り出して読む（Artifact の read に `path` で id を渡す）。画像には実物の規約やマンション名が写りうるので、**リポジトリ・コミット・`docs/checks/` には決して入れない**。取り出した画像は作業用の一時フォルダにだけ置く。

## 項目の書き方

- やること・見るところ（期待する結果）・人の確認が要る理由・場所を書く
- AI の費用がかかる項目は、節の見出しに費用の目安を書く
- 専門用語を避け、画面の言葉で書く

## 公開してよいこと

このリポジトリは公開されている。記録には、実在のマンション名・住民の情報・実物の規約の文を書かない。
「印刷：表の見出しが各ページにくり返されることを確認」「第◯条の文が長く、改行が不自然（架空のサンプルで再現して修正）」のように、場所と事実だけを書く。
