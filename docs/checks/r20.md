## 変えたこと

- 計画B：ステップ4の議題の判断を、プルダウンからステップ2と同じボタンにした。段ごとの案（①理解した／②採用・修正して採用・見送り／③確認した・要修正）と「未判断」が並ぶ。選ぶとすぐ保存するのは今のまま。スマホでは、案が4つの段を2行に並べる
- 計画C：スマホ（幅720px以下）の新旧対照表で、条を項ごとに分けて見比べる形にした
  - 変わっていない項は「変わっていない項（第3項・第4項）を見る」に折りたたむ
  - 少しだけ変わった項は、加えた語句に色、消した語句に赤の取り消し線を付けて、1つの文の中で示す
  - 書き換えが多い項（現行の語句の残りが6割未満）だけ、改定案と現行を上下に並べる
  - 項を加えて番号だけ繰り下がった項は「第4項（現行の第3項）」として組む。号（一、二…）は前の項に含める
  - 新しく加える条・削る条・1つの項だけの条は、今までどおり
  - パソコンと印刷の表、Word・Markdown は今のまま。前に作った表も、開いたときに今の作りで書き直す（AI は使わない）

- 1-1（新旧対照表）：お使いの規約の作業で、スマホの幅で確認できた
