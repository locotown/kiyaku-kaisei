下書き（482字。改行を除く）：

> このプロジェクトは、マンションの管理規約の見直しを担う理事・委員（専門家ではない人）が、2026年4月施行の改正区分所有法に規約を合わせる作業を、根拠付きの改定案と総会の資料づくりまで自分たちで進められるようにするWebツールです。
>
> 改正に合わない規約は、施行後に効力を失うおそれがあります。しかし専門家に頼めない管理組合も多く、条文を読み解いて改定案を作るのは担当者に大きな負担です。
>
> 使い方：現行の規約（Word・PDF）を読み込むと、AIが改正法と標準管理規約に照らして、直す必要がある箇所を根拠の条文付きで洗い出します。委員会が採否を判断すると、改定案と新旧対照表、理事会の検討資料、住民向けの説明文までを作ります。資料はA4で印刷でき、Wordでも保存できます。
>
> 会議では印刷した資料に手書きで書き込み、スマホで撮って戻すと、AIが読み取って反映の提案にします。委員会が手で直した条文は、AIが法律に合っているかを根拠付きで確かめます。作者自身が規約見直し委員会の委員として、実物の規約で使いながら作りました。出力は総会提案の下書きで、法的助言ではありません。

#### Agent SDK の検討（11/5）
- 作品の AI の部分は、Anthropic 側で動く Managed Agents に任せている。利用者のパソコンに道具を入れずに済み、止まっても続きから再開できるので、この作品の使う人（専門家ではない理事・委員）に合っている
- Agent SDK は、エージェントを自分の環境（手元のパソコンやサーバー）で動かすための道具。作品に入れるなら、置き換えではなく、別の役目で使うのが自然
- 候補は「開発の道具」側：改定案の採点役の差し戻し理由を集計し、スキルに足す注意書きの案を作る作業（docs/plans/検証ループ.md の L2。今は evals/lessons.py と人の判断で回している）を、Agent SDK のエージェントにする
- 締め切りまでの日数と効果を比べて、入れるかどうかを決める。チェックを付けるためだけには入れない

### 開発中に一番詰まった場面（①〜⑤の順で）
**今は案A**（11/5 決定。今後変わるかもしれない）。下書きを2つ用意した。

**案A：AI の作業が途中で止まったときの費用（Claude の機能に関わる。今の選択）**
- ①何を作ろうとしていたか：AI に改定案を作らせる処理（Managed Agents で10分前後かかる）
- ②どう指示したか：作者が実物の規約で試している最中に、作業環境（Codespace）が止まった。「途中で止まったらやり直し？やり直すと AI の費用がもう一度かかるのが気になる。途中から再開できないか」と頼んだ
- ③何が起きたか：止まった作業は「作成中」のまま残り、ボタンも押せなくなっていた。最初の対策では「途中で止まった」と表示して作り直してもらうだけで、費用は二重にかかった
- ④期待との違い：作者は費用をかけずに続きから進めたかった
- ⑤どう対処したか：Claude が、Managed Agents のセッションは Anthropic 側に残っていることに着目し、つなぎ直したときにこれまでのイベントを読み、答えていない道具の呼び出しにだけ答えて続ける仕組みを作った。通信の切断は自動でつなぎ直し、サーバーが止まったときは「途中から再開する」を出す。本物の AI で、途中で強制終了して2分待ち、再開して完成することを確かめた（費用はセッション全体で約$1.76、二重にかかっていない）

**案B：作業環境で画面が開かない（Claude 以外の原因）**
- ①画面を確かめながら、実物の規約で試そうとしていた（GitHub Codespaces）
- ②画面のスクリーンショットを Claude に送り「表示されない」と伝えた
- ③Claude はターミナルの記録から、開いた直後に拡張機能が Ctrl+C を送ってサーバーを止めていることを見つけて直した。それでも 404 が続いたため、Codespace の中では正常（200）で外からだけ 404 になることを確かめ、Codespaces のポート転送の不具合と判断した
- ④Codespaces なら専門家でなくても手軽に使えると考えていたが、何度も止まった
- ⑤手元の Mac で動かす手順に切り替え、README に残した

## 公開の形と今後の展開（11/5 決定）
- 提出は「管理組合が自分の API キーを入れて使う形」。AI の費用は各組合に、使った分だけかかる（一通しで約 $2〜10）。Claude のサブスクリプションとは別
- 初めてのキーで AI を使うと、AI の設定（エージェント）を自動で登録する。利用者がコマンドを実行する必要はない。作者のキーは今の登録をそのまま使う
- 今後は、API キーを用意しなくても使えるサービスとして提供する計画（docs/plans/今後の展開.md）。提出文とデモ動画の最後で一言ふれる
- **今回の提出はβ版、イベントのあとに正規版**（11/7 作者の判断）。正規版では、法令と標準管理規約（国交省のコメントを含む）を条ごとに整理し、原文の引用で裏付けた独自の知識ベースを裏で使う。知識ベースの中身と作り方は非公開で、このリポジトリにはβ版と、知識ベースの入口（core/kb.py）だけを置く
  - 11/7 の試作で効果を確かめた：標準管理規約が断定せず各マンションに任せている点（役員の任期、理事会の招集の決まり、暴力団員への貸与の禁止）について、同じ質問を相談の AI に聞くと、β版は「国交省のコメントを確かめられない」と答えたが、知識ベースを使うと、コメントを根拠に目安と選択肢を示した（挙げた根拠は原文と照合して確認）。1回の費用はほぼ同じ（約$0.12〜0.16）
  - 提出文で使うなら（案）：「今回の提出はβ版です。正規版では、法令と国の標準管理規約を条ごとに整理した独自の知識ベースを裏側で使い、『規約で各マンションが決めること』を根拠付きで示します。試作では、同じ質問への答えが、国の解説を根拠にした具体的な目安と選択肢に変わりました。」
