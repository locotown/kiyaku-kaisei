# ととのう規約 デザインシステム

管理組合の理事・規約見直しの担当者（年配の人を含む、専門家ではない人）が、迷わず、落ち着いて使える画面にするための約束。
11/4 に決めた第3案（docs/plans/デザイン見直し.md）をもとにしている。

- **トークンの正本は `app/static/tokens.css`、部品の見た目の正本は `app/static/components.css`**。値を変えるときはそのファイルだけを変え、このページの表も合わせる
- Claude のデザインシステム（Design System の型の Artifact、非公開：https://claude.ai/artifact/3hMhGegDNYLML5jUFVD6F8 ）は、この2つを写したもの。部品11個の見本・ブランドブック・ロゴ・表紙を持つ。食い違ったら、リポジトリのほうが正しい。変えたら写し直す
- 部品の見た目の見本：docs/plans/design/v3/（指摘の判断・スマホの幅・改定案・総会）、作り方は docs/plans/design/mock3.py

## 原則
1. **次にすることは、いつも1つ。** 画面の下に固定した帯に、主のボタンを1つだけ置く
2. **要約を先に、詳細はあとで。** 各ステップの冒頭に、件数の要約。指摘は最初は1行に畳み、開いて読む
3. **箱で区切らず、余白と細い線で区切る。** 箱にするのは、開いた指摘など1段だけ。箱の中に箱は作らない
4. **主の色は藍の1色。朱は判子だけ。** 区分の色は彩度を落とし、色だけに頼らず文字のラベルと一緒に使う
5. **判子は、人が記録した結果だけ。** 総会の「可決」と、人が判断したステップの「済」。AI が作った下書きには押さない
6. **年配の人にも読める。** 本文は 18px 以上、押す場所は高さ 44px 以上、文字のコントラストは 4.5:1 以上。「文字を大きく」でさらに 1.125 倍
7. **言葉は、使う人の言葉。** 「採用」ではなく「改定案に入れる」。内部の名前（論点ID、satisfied など）は画面に出さない
8. **間違えても怖くない。** 判断は「選ぶ → 理由 → 確定する」で保存し、取り消せて、履歴が残る。画面の操作でページが勝手に動かない

## 部品
| 部品 | 見た目 | 決まりごと |
| --- | --- | --- |
| ヘッダー | 白い面、下に細い線。左にロゴ（藍の角丸の四角に、そろった3本の線）と「ととのう規約」、説明の一行「管理規約を、改正法に合わせる」。右に文字だけのボタン（文字の大きさ・使い方・これまでの見直し） | ロゴは判子に見えない形にする |
| 進み具合（回覧） | 細い線でつないだ6つの丸と、その下のステップ名。いまのステップは藍の点、済んだ AI のステップは線のチェック、済んだ人のステップは小さな朱の「済」 | 「済」の判子は人が判断したステップ（指摘の判断・理事会での検討・総会のあと）だけ |
| ステップの見出し | 小さな「ステップ 2 ／ 6」、28px の見出し、その下に一文の説明 | 説明は、このステップで何を決めるかを件数で言う |
| 要約の数字 | 上下に細い線、3列、ラベル（14px）と大きな数字（36px）。進み具合は細い棒 | 数字は実際の件数から出す |
| タブ（絞り込み） | 文字と件数。選んだタブは太字と藍の下線 | 丸い札にしない |
| 指摘の行（畳んだ形） | 区分のラベル（色の文字と左の細い線）、題名（18px 太字）とその下の「何が変わるか」の一文、右に状態と開く印。行の間は細い線 | 1行で何の話か分かる題名にする |
| 指摘の行（開いた形） | 白い面、細い枠、丸み 6px。今の規定・根拠（下線つきのリンク）・判断の切り替え・理由・確定する | 箱はここだけ |
| 判断の切り替え | 3つに区切った枠。「改定案に入れる」「今回は見送る」「あとで決める」。選んだものは藍の薄い地、藍の文字、下線、チェックの線のアイコン | 保存する値は 採用 ／ 不採用 ／ 保留 のまま |
| ボタン | 主のボタン：藍の地、白い太字、高さ 48px、丸み 6px。ほかは文字だけのボタン（藍の太字） | 主のボタンは1画面に1つ |
| 下に固定する帯 | 白い面、上に細い線。左に状況の一文、右に主のボタン | 保存の帯と次の一手を1つにまとめる |
| 判子 | 朱の円、少し傾ける。「可決」「済」 | 人が記録した結果だけ |
| 文書の枠 | 白い面、細い枠。左にファイルのアイコン、題名と注記、右に主のボタン | 最新の規約・新旧対照表などの成果物 |
| アイコン | 線のアイコン（Lucide の形。MIT）をページに直接書く。太さ 2、角は丸める | 外部から読み込まない。記号の文字（✓ ▾ →）で代用しない |

## 壊さないもの（画面の動き・テスト・録画が使っている）
- ID・クラス：`#findings-fold`、`.fcard`、`.decbox`、`#bulk`、`#bk-scope`、`#bk-dec`、`#bk-go`、`#questions`、`#flist-top`、`#filters`、`.fbtn`、`.basis`、`#progress`
- フォームの名前：`decision_*`、`reason_*`、`b_decision_*`、`b_q_*`、`b_note_*`、`m_result_*`、`m_edit_*`、`m_name`、`m_date`
- アンカー：`#findings`、`#next`、`#board`、`#explain`、`#meeting`。ステップの切り替えは URL の `#ステップ名` で選ぶ
- 判断の値：採用 ／ 不採用 ／ 保留

## 書かないこと
- 画面と出力は日本語だけ
- 「総会提案の下書きであり、法的助言ではありません」の表示は消さない
- 実在のマンションの写真・名前・住民名・部屋番号は使わない
