# 審査員向けの公開版を出す（Render）

審査員が実際に操作できるように、ログインと期限付きで公開する手順（11/8 作者の判断）。
手元で使うだけなら、この手順は要らない（docs/SETUP.md）。

## しくみ（何を守るか）

- **ログイン**：ID とパスワード。パスワードはハッシュで持ち、失敗が続く相手は15分受け付けない（`core/auth.py`）
- **期限**：アカウントごとの最後の日（日本時間）を過ぎるとログインできない。12時間操作がなければログインし直し
- **他の人のデータ**：作業と相談に持ち主を記録し、自分のものだけが見える・開ける（作者用の管理者アカウントは全部）
- **AI の費用**：アカウントごとの上限（既定 $20）と全体の上限（既定 $200）を超えると、新しい AI の処理を始めない。さらに、公開用だけの API キーに Console で使用額の上限を付ける（こちらが本当の止め）
- **初めの状態**：ログインすると、架空のサンプルで総会まで済んだ作業の写しがすぐ見られる。サンプルの規約やお手元の規約を読み込んで、AI の点検から試すこともできる
- 秘密の値（API キー・アカウントの一覧）は Render の環境変数にだけ置く。リポジトリには入れない。公開版の URL・ID・パスワードは提出フォームの項目11にだけ書く

## 手順（作者が行う。30〜60分）

### 1. 公開用の API キーを作る（Anthropic Console）
1. Console で、公開用のワークスペースを作る（例：「totonou-public」）
2. そのワークスペースの使用額の上限（Spend limit）を決めて設定する（例：$200）
3. そのワークスペースで API キーを作る。表示された値を控える（一度しか表示されない）

### 2. アカウントを作る（手元の Mac のターミナル）
```bash
cd ~/kiyaku-kaisei && git pull && uv run python scripts/make_accounts.py --judges 5 --until 2026-11-12 --out ~/kiyaku_accounts.txt
```
- 画面に出る1行（`[{"id":"judge1",...}]`）を、次の手順で Render の `KIYAKU_ACCOUNTS` に貼る
- ID とパスワードの一覧は `~/kiyaku_accounts.txt`（リポジトリの外。コミットしない）。提出フォームの項目11に使う
- 作者用のアカウント `author` は管理者（全員の作業を見られ、費用の上限がかからない）

### 3. Render で公開する
1. https://render.com にログインし（GitHub でサインインできる）、GitHub の locotown/kiyaku-kaisei へのアクセスを許可する
2. 「New」→「Blueprint」→ リポジトリ locotown/kiyaku-kaisei を選ぶ（リポジトリの `render.yaml` を読み、Docker・常に動くプラン・1GB のディスク・`/healthz` を設定する）
3. 環境変数を入れる（値が秘密のものは画面でだけ）：
   - `KIYAKU_ANTHROPIC_API_KEY`：1 で作った公開用のキー
   - `KIYAKU_ACCOUNTS`：2 で出た1行
   - `KIYAKU_SESSION_SECRET` は自動で作られる。`KIYAKU_LIMIT_USER_USD`（20）と `KIYAKU_LIMIT_TOTAL_USD`（200）は必要なら変える
4. 「Apply」を押す。最初の組み立てに数分かかる。料金は Render の画面で確かめる（常に動くプランとディスクは有料）
5. できた URL（`https://….onrender.com`）を開き、ログインの画面が出ることを確かめる

### 4. 確かめる（作者）
- [ ] judge1 でログインし、トップに「審査用の公開版です（○月○日まで）」と出る
- [ ] サンプルの作業（想定ユーザーの作業の写し）が開ける
- [ ] 「サンプルで試す」で新しい作業を作り、AI の点検が進んで終わる（初めてのキーでは、AI の設定の登録に1分ほどかかる）
- [ ] judge2 でログインし直し、judge1 の作業が一覧に出ない
- [ ] ログアウトして、作業のアドレスを直接開くと、ログインの画面になる

### 審査が終わったら
- Render のサービスを止めるか消す（ディスクの中の作業・読み込んだ規約も消える）
- Console で公開用の API キーを無効にする
