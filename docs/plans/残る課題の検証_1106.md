## 計画（作者の承認を待つ）

### 計画A：今の規約の（ア）（イ）の両案を、理事会で選べるようにする（11/7 実装済み）

- 何が困るか：標準管理規約をもとにした規約には、「民泊を認めるか（第12条）」「メールなどの電磁的方法を使うか（第31条など多数）」のように、どちらかを選ぶ両案が書かれている。今は最新の規約に両案とも残り、Word で手で消す必要がある
- やること
  1. 点検のあと、今の規約の両案（「〔ア案〕」「（ア）…の場合」の見出しで分かれているもの）を、条ごとに機械で取り出す（AI を使わない）
  2. ステップ4の「組合が選ぶ点」に、改定案の〔選択〕と並べて「今の規約の両案」として出す。電磁的方法のように多くの条で同じ選択（ア：使わない／イ：使う）になるものは、1問にまとめる
  3. 選んだ案だけを、最新の規約・新旧対照表に残す（AI を使わない。条の文はそのまま）。選ばなければ今と同じく両案を残して知らせる
  4. 本文の同じ行につながった別案（PDF などから写したもの）は、機械で正しく分けられないので、知らせるだけにする
- 費用：AI は使わない。作業は半日ほど
- 確かめ方：自動テスト、標準管理規約のサンプルで通し（理事会で選ぶ → 最新の規約に片方だけ残る）
- 注意：両案のどちらを選ぶかは、改正とは別の組合の判断（総会の決議が要る）。画面では「今回の改正とは別に、組合で採用している案を選ぶ」と書く

### 計画B：ステップ4の判断を、ステップ2と同じボタンの形にする（11/7 実装済み）

- 今：議題ごとに「（未判断）」のプルダウン。ステップ2は「入れる／見送る／あとで」のボタン
- やること：段ごとの選択肢（①理解した、②採用・修正して採用・見送り、③確認した）をボタンにする。選ぶとすぐ保存（今と同じ）。〔選択〕のある議題は、ボタンの下に問の案を並べる
- 費用：AI は使わない。作業は数時間。想定ユーザー（AI を使わない操作だけ）で確かめる

### 計画C：スマホの新旧対照表を見比べやすくする（11/7 実装済み）

- 今：スマホでは改定案と現行を上下に並べ、長い条は画面の何枚分にもなる
- やること（案）：スマホでは、条を項ごとに分けて「改定案の項 → 現行の項」を交互に並べ、変わっていない項は折りたたむ（「変わっていない項も見る」で開く）。印刷とパソコンの表示は今のまま
- 費用：AI は使わない。作業は数時間
- 実装（11/7）：項ごとに組み、変わっていない項は折りたたむのは案のとおり。項を交互に並べるだけでは見出しと札のぶん、かえって長くなった（第49条で 4,501px → 5,780px）ため、少しだけ変わった項は加えた語句に色・消した語句に赤の取り消し線を付けて1つの文の中で示し、書き換えが多い項（現行の語句の残りが6割未満）だけ上下に並べる形にした（4,146px）。前に作った表も開いたときに書き直す
