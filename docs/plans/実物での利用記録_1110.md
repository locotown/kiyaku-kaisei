# 実物の規約で使った結果を数字で残す（11/10 作者の判断）

審査日の比較で、上位の作品は「実際に使った結果」を数字で示していた。ととのう規約は架空の規約での評価だけだったため、作者の管理組合で実物の規約に使った結果を、数字だけで残す。

## 残し方
1. 作者の Mac で、実物の作業を選ぶ：`uv run python scripts/usage_report.py`（作業の一覧。名前は画面にだけ出る）
2. 数字をまとめる：`uv run python scripts/usage_report.py <作業ID>`
   - 作業の記録から、指摘の数（必須・推奨・参考）、採用の割合、改定の数、委員会で直した条の数と AI の確認の結果、理事会の判断、写真の書き込み、総会の結果、AI の費用を出す
   - 規約の文・マンション名・作業の名前・人の名前は出さない
   - `private/reports/<作業ID>.md` に保存する（コミットしない）
3. 出力の「人が記録すること」に書き足す：委員会・理事会でかかった時間、ツールなしの場合の見込み時間、専門家に頼んだ場合の見積もり、AI の誤りだと判断した数、住民からの質問の数、委員の感想
4. 公開してよい形（割合・件数・時間の比較）だけを選んで、README や発表に載せる。載せる前に、実在の管理組合が分かる情報がないか作者が確かめる

## 次に、この数字と並べたいもの
- Claude だけの場合との比較（架空ではない古い規約で、見落としと誤りの数）。別の計画にする
