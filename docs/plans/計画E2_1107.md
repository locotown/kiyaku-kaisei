# 計画E2：条の対応表に、理事会の判断（残す・見直す・なくす／足す・足さない、いつ扱うか）を記録する（11/7 案。作者の承認待ち）

## ねらい

条の対応表（E1）で、今の規約と標準管理規約の違いの量と場所が分かった。作者の確認（第25回）のとおり、これを見て「今後徐々に規約改定をしていく判断」をする。
E2 は、その判断を対応表の行ごとに記録し、①今回の一部改正に入れるもの、②次回以降の宿題、③今のままでよいもの、に仕分けられるようにする。

## 判断の選び方（行の種類ごと）

| 対応表の行 | 選べる判断 |
| --- | --- |
| 違う（標準管理規約と文が違う） | 今のまま／標準に合わせる |
| 今の規約だけ（独自の決まり） | 残す／見直す／なくす |
| 標準にあって今の規約にない | 足さない／足す |
| ほぼ同じ | 判断は要らない（表示だけ） |

「標準に合わせる・見直す・なくす・足す」を選んだ行は、いつ扱うかも選ぶ：**今回の改定案に入れる**／**次回以降（宿題）**。メモ欄（理由・経緯）を付ける。選ぶとすぐ保存する（ステップ2・4と同じ）。

## 2つに分けて作る

### E2a：判断を記録し、宿題の一覧を出す（AI は使わない・半日）

- 対応表に「判断を記録する」画面を足す（ステップ1の対応表の入口から。印刷の対応表には判断の欄を出す）
- 判断の集計：今回入れる N件・次回以降の宿題 N件・今のまま／残す N件・未判断 N件
- 印刷できる「規約の見直しの宿題一覧」：次回以降にした行を、判断・メモと一緒に並べる。次の理事会・総会に引き継ぐ資料
- 次の作業への引き継ぎ：新しい作業（来年の見直し）を読み込むときに「前の作業の判断を引き継ぐ」を選べるようにする。標準管理規約の条番号と今の規約の見出しで行を合わせる

### E2b：「今回の改定案に入れる」にした行を、改定案づくりに渡す（AI を使う）

- 「今回」にした行を、「理事会が対応表から足した見直し」としてステップ2に出す（判断は「入れる」から始まる。見送りにもできる）
- 改定案を作るとき、ほかの指摘と一緒に AI に渡す。「標準に合わせる」「足す」は標準管理規約の条を手本に、今の規約の条番号・言い回しに合わせて書く
- 改定案をもう作ってある場合は、「対象の条だけ作り直す」で足す（全体は作り直さない）
- 新旧対照表・検討資料・住民向けの説明では、法改正への対応と分けて「理事会の判断による見直し（法改正とは関係ない）」と示す
- 費用の目安：足す・合わせる条1か条あたり 約$0.1〜0.4（対象の条だけ作り直す場合）

## 決めていただきたいこと

1. **進め方**：E2a（記録と宿題の一覧、AI なし）を先に作り、使ってみてから E2b（改定案に入れる）に進む、でよいか
2. **次の作業への引き継ぎ**：来年の見直しのために、前の作業の判断を引き継ぐ機能は要るか（E2a に含めるか）
3. **根拠の扱い（E2b）**：CLAUDE.md の「根拠を示せない指摘は出さない」は、AI が出す指摘の決まり。理事会が対応表から足した見直しは AI の指摘ではないので、根拠の欄は次のようにしてよいか
   - 「標準に合わせる」「足す」：標準管理規約の条番号
   - 「なくす」「見直す」：「理事会の判断（日付）」
   - どちらも、法改正への対応ではないと明記する

## 気をつけること

- 一部改正（A）の範囲が広がりすぎないように：今回に入れる件数が多いときは、「議案の説明と合意の負担が増えます。法改正への対応と別の議案に分けることも考えてください」と知らせる
- 細則は対応表の対象外（標準管理規約に細則はない）。細則の見直しは計画F2・F3で扱う
- 対応づけの誤り（別の条と対応づけている）を、人が直せるようにする（E2a で「対応する標準の条」を選び直せる欄）
