# デザインの見直し：計画とラフ案（11/3 夜。承認待ち）

機能がほぼそろったので、見た目と使い勝手を見直す。大きな変更なので、この計画とラフ案（docs/plans/design/比較.png）の承認を得てから実装する。
もとのメモは docs/DESIGN_IDEAS.md。

## 1. どの方向にも共通する前提
### 変えないこと
- 画面と出力はすべて日本語（動画の字幕だけ英語）
- 「総会提案の下書きであり、法的助言ではない」の表示
- 実在のマンションの写真・名前・住民名・部屋番号は使わない（イラストと架空のサンプルだけ）
- Streamlit は使わない（FastAPI と HTML のまま）
- 名前「ととのう規約」と説明の一行「管理規約を、改正法に合わせる」

### 想定ユーザーへの配慮（理事・規約見直しの担当者。年配の人を含む、専門家ではない人）
- 本文は 17〜18px 以上。文字と背景のコントラストを十分に取る
- 押す場所（ボタン・選択肢）を大きくする
- 「次にすること」を、いつも1つだけ、画面の上に示す
- 専門用語には、その場で短い説明を添える（今の仕組みを続ける）

### どの方向でも入れる構造の変更
通しテストの課題（docs/reviews/20261103_通しテスト.md の 10・11）とユーザーの指摘への答え。
1. **作業ページを段階ごとに分ける**：今は約8,000px の1枚のページ。6つの段階（読み込み／指摘の判断／改定案／理事会での検討／住民向けの説明／総会後の最新規約）を切り替えて、1度に1つの段階だけを見せる。進み具合はいつも見える
2. **トップ画面**：「これまでの見直し」を上に置き、最後の更新日時・いまの段階・削除を付ける。新しく始める入力欄は短くし、詳しい説明は開いて読む形にする
3. **サンプルでも、メールや Web の利用（電磁的方法）を選べるようにする**（通しテストの課題）

### 判子の使い方
判子は、**人が記録した結果**（総会の「可決」、理事会の判断済み）にだけ使う。AI が作った下書きに、承認の印に見える判子は押さない（誤解を招くため）。

### 壊さないこと
- 画面の動きと録画・テストのスクリプト（docs/demo/video/record.js、E2E）が使っている ID・クラス・名前は残す。変えるときはスクリプトも直す
  - 例：`#findings-fold`、`.fcard`、`.decbox`、`#bulk`、`#bk-*`、`#questions`、`b_q_*`、`decision_*`、`b_decision_*`、`m_result_*`、`#flist-top`、`#filters`
- テスト 83件を通す

## 2. 3つの方向（ラフ案：docs/plans/design/比較.png、各画面は docs/plans/design/{A,B,C}_*.png）
各方向で、同じ4画面を比べる：① トップ ② 指摘カード（作業画面）③ 総会の結果と最新の規約 ④ 指摘カード（スマホの幅）

| | A 規約集 | B 掲示板・回覧板 | C すっきり手順 |
| --- | --- | --- | --- |
| 狙い | 信頼感・きちんと感（規約集のような書類） | 管理組合らしい親しみ | 迷わない使いやすさ |
| 色 | 生成りの地、朱（差し色）と藍 | 掲示板の地、白い掲示物、深緑（回覧板）と朱 | 白と淡い灰、青ひとつ、朱は判子だけ |
| 字体 | 見出しだけ明朝（Noto Serif JP）。本文はゴシック | ゴシック（太め） | ゴシック、本文 18px |
| 段階の見せ方 | 左に目次（第一〜第六） | 左に回覧板。済んだ段に「済」の印 | 上に大きな6つのタブ（ステップ 2 / 6） |
| 指摘カード | 規約集のページ（上に区分の色の線） | 画びょうで留めた掲示物、「必須」のテープ | 罫線の白いカード、文字が大きい |
| 日本の要素 | 判子、規約集の体裁、和数字の章 | 掲示板、回覧板の押印欄、可決の判子 | 可決の判子だけ |
| 良いところ | 法律の書類らしい落ち着き。総会資料と見た目がそろう | 「マンションの道具だ」とひと目で分かる。海外の審査員への驚きが一番大きい | 年配の人にも一番迷いにくい。画面が広く使える |
| 気になるところ | 堅く古く見えるおそれ | 遊びが強いと、真剣さが減るおそれ。画面の装飾が多い | 日本らしさ・驚きは弱い |

## 3. おすすめ：C を土台に、B の要素を2か所だけ足す
- 土台は **C**（1度に1つの段階、大きな文字、上に進み具合、次にすることを1つだけ）。想定ユーザー（年配の人を含む、専門家ではない人）が一番迷わない
- 日本らしさは **B から2か所だけ** 借りる：
  1. 進み具合の表示を、回覧板の押印欄にする（済んだ段に「済」の印）
  2. 総会の結果の「可決」を判子で示す（人が記録した結果だけ）
- 理由：使う人の分かりやすさを最優先しつつ、デモ動画で見せる場面（進み具合・総会の可決）で日本らしさが伝わる。装飾を2か所に絞るので、実装も短く済む
